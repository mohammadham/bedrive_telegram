# BeDrive Enhanced - پلتفرم ذخیره‌سازی فایل با ادغام تلگرام

BeDrive Enhanced یک نسخه بهبودیافته از پلتفرم محبوب BeDrive است که با افزودن قابلیت‌های قدرتمند جدید، تجربه مدیریت و اشتراک‌گذاری فایل‌ها را به سطح جدیدی می‌برد. این پروژه با تمرکز بر ادغام با تلگرام، یک سیستم API جامع و ابزارهای پیشرفته اشتراک‌گذاری، راه‌حلی کامل برای نیازهای ذخیره‌سازی مدرن ارائه می‌دهد.

## ✨ ویژگی‌های کلیدی

- **ادغام کامل با تلگرام**:
    - **درایور ذخیره‌سازی تلگرام**: فایل‌ها را مستقیماً در تلگرام ذخیره کنید.
    - **ارسال خودکار**: یک کپی از فایل‌های آپلود شده را به صورت خودکار به کانال یا چت تلگرام ارسال کنید.
    - **مدیریت Session**: به راحتی session تلگرام خود را از طریق پنل ادمین مدیریت کنید.
- **سیستم API جامع**:
    - **احراز هویت مبتنی بر توکن**: با استفاده از توکن‌های امن به API دسترسی پیدا کنید.
    - **مدیریت کامل فایل‌ها**: Endpoints کامل برای آپلود، لیست، دانلود و حذف فایل‌ها.
    - **مدیریت تنظیمات کاربر**: کاربران می‌توانند تنظیمات تلگرام خود را از طریق API مدیریت کنند.
- **آپلود از URL**:
    - فایل‌ها را مستقیماً از لینک‌های اینترنتی دانلود و در حساب خود ذخیره کنید.
- **سیستم اشتراک‌گذاری پیشرفته**:
    - **لینک‌های کوتاه**: لینک‌های کوتاه و امن برای اشتراک‌گذاری فایل‌ها ایجاد کنید.
    - **محافظت با رمز عبور**: برای لینک‌های اشتراک‌گذاری خود رمز عبور تعیین کنید.
    - **تاریخ انقضا و محدودیت دانلود**: کنترل کاملی بر روی دسترسی به فایل‌های اشتراک‌گذاشته شده داشته باشید.

## 🚀 نصب و راه‌اندازی

برای نصب و راه‌اندازی پروژه، لطفاً مستندات کامل موجود در `documentation.html` را مطالعه کنید.

### پیش‌نیازها

- PHP 8.1+
- Composer 2.0+
- Node.js 16.0+
- MySQL 5.7+ or PostgreSQL 10+
- Python 3.7+ (برای ادغام تلگرام)
- `pip install telegram-upload`

## ⚙️ پیکربندی

### تنظیمات تلگرام

1.  به [my.telegram.org](https://my.telegram.org) بروید و `API ID` و `API Hash` خود را دریافت کنید.
2.  وارد پنل ادمین شوید و به بخش `Settings > Drive` بروید.
3.  اطلاعات API تلگرام خود را در بخش مربوطه وارد کنید.
4.  بر روی دکمه "Configure Session" کلیک کرده و session تلگرام خود را راه‌اندازی کنید.
